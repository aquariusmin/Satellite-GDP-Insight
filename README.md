Satellite-GDP-Insight : 야간 위성 조도를 활용한 국가별 GDP 예측 분석

"신뢰할 수 있는 통계가 부족한 지역의 경제 수준을 위성 데이터로 읽어내다."
본 프로젝트는 비정형 위성 데이터를 수치화하여 경제 지표로 변환하고, 이를 통해 국가별 경제 수준을 예측하는 대안적 분석 모델을 제안합니다.

1. 프로젝트 배경 (Background)
- 문제 정의: 저개발 국가나 분쟁 지역, 혹은 통계 폐쇄 국가의 경우 공식적인 GDP 데이터의 신뢰도가 낮거나 부재하여 글로벌 비즈니스 의사결정에 제약이 발생함.
- 아이디어: "인간의 경제 활동이 활발할수록 밤의 밝기도 밝을 것이다"라는 가설 아래, 야간 조도 데이터를 GDP의 대리 지표(Proxy Indicator)로 활용.

2. 데이터셋 및 분석 환경 (Dataset & Environment)
- 데이터 범위: 2019년 ~ 2023년 (5개년), 전 세계 주요 국가 대상
- 데이터 구성:
  > 독립 변수: 야간 위성 조도 합계 (Brightness Sum)
  > 종속 변수: 국내총생산 (GDP)
  > 조절 변수: 도시 인구수 (Urban Population), 전력 접근성 (Electricity Access)
- 활용 도구: SPSS, Python, Excel

3. 분석 방법론 (Methodology)
1) 데이터 수집 및 정제: 비정형 이미지 기반의 조도 데이터를 국가 단위 수치 데이터로 변환 및 결합.
2) 상관관계 분석: 조도 값과 실제 GDP 간의 정(+)의 상관관계 검증.
3) 회귀 분석 수행: 단순 회귀 분석을 시작으로, 인프라 요인을 포함한 다중 회귀 및 조절 효과 분석 수행.
4) 조절 효과 검증: 도시 인구 비중과 전력 인프라 수준이 '조도-GDP' 관계를 어떻게 강화하는지 분석.

4. 핵심 결과 및 인사이트 (Key Results)
- 설명력: ln(GDP)를 ln(야간 조도)에 회귀했을 때 R^2 = 0.819 (N = 791, 기울기 0.834, p < 0.001). 표본 내 GDP 변동의 81.9%를 설명한다는 뜻이며, 예측 정확도나 인과관계를 의미하지 않습니다.
- 조절 효과: 도시인구·전력접근성을 함께 넣은 주효과 모형은 R^2 = 0.854, 상호작용항까지 넣으면 R^2 = 0.862입니다. 상호작용은 유의하지만(p < 0.001) 설명력 증가분은 ΔR^2 = 0.009로 작습니다.
- 대안 지표로서의 가치: 통계 인프라가 미비한 국가의 실질 경제 수준을 가늠하는 보조 지표로서 활용 가능성 제시.
- 한계: 위성 관측 조건, 결측, 비경제적 조명(가스 플레어·어선 등)이 해석을 제약합니다.

5. 비즈니스 활용 방안 (Strategic Application)
- 시장 진입 전략: 공식 통계가 없는 신흥 시장 진출 시, 위성 데이터를 활용한 시장 규모 및 소비 잠재력 추정.
- 리스크 관리: 국가적 위기나 급격한 경제 변동 상황을 실시간 위성 데이터를 통해 선제적으로 모니터링.

6. 결과 재현 (Reproducibility)

```bash
pip install -r requirements.txt
python reproduce.py
```

`reproduce.py`는 SPSS 파일(.sav)을 읽어 위 세 모형을 다시 계산하고 `outputs/`에 저장합니다.
이력서와 포트폴리오에 쓰는 R^2 = 0.819는 이 스크립트가 출력한 값입니다.

| 모형 | R^2 | 수정 R^2 | 관측치 |
|---|---|---|---|
| 단순회귀 ln(GDP) ~ ln(조도) | 0.8189 | 0.8187 | 791 |
| 주효과 조도 + 도시인구 + 전력접근성 | 0.8538 | 0.8532 | 786 |
| 조절효과 상호작용항 추가 | 0.8623 | 0.8614 | 786 |

7. 데이터 파일 주의사항

- **기준 데이터는 `.sav`입니다.** 로그 변환과 평균 중심화가 적용된 분석용 데이터이며, 보고서의 결과가 이 파일에서 나왔습니다.
- **`.xlsx`의 조도 열은 GDP 열과 어긋나 있습니다.** `.sav`와 국가-연도로 대조하면 GDP는 776/776 일치하지만 조도는 5/675만 일치합니다. 같은 행끼리 계산한 ln(GDP)–ln(조도) 상관이 `.sav`에서는 0.905인데 `.xlsx`에서는 -0.012로 무너집니다.
- 따라서 `Satellite_GDP_Insight.py`(xlsx를 읽습니다)의 출력은 신뢰할 수 없습니다. 이 스크립트가 보고하던 R^2 = 0.877은 조도가 아니라 도시인구·인구가 만든 값이며, 조도를 빼도 R^2가 같습니다. 재분석에는 `.sav` 또는 `reproduce.py`가 생성하는 `outputs/analysis_dataset.csv`를 쓰세요.
